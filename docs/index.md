# 🚆 Railway Track Inspector

AI-assisted railway track fault screening from images.

## 👉 [Open the live app](https://railway-track-inspector.streamlit.app)

## About
- Dataset: Kaggle Railway Track Fault Detection (224×224)
- Model: MobileNetV2 transfer learning with Grad-CAM explainability
- Source code: [GitHub](https://github.com/192525146simats-beep/Computer-Vision/tree/main/railway-fault-detector)

> Research prototype. Not a railway safety certification.
