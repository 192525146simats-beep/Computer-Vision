# Computer Vision Lab Experiments

A collection of 40 hands-on Computer Vision experiments implemented in Python using OpenCV and Jupyter Notebooks (`.ipynb`). This repository covers core image processing, geometric transformations, morphological operations, object/face detection, and video analysis.

---

## 📂 List of Experiments

| Exp. No. | Experiment Title / Description |

| **Exp 01** | Read an image using Python and convert it to Grayscale. |
| **Exp 02** | Read an image and apply Gaussian Blur. |
| **Exp 03** | Read an image and display the image outline using the Canny edge detector. |
| **Exp 04** | Implement Histogram Equalization and compare it with the original image using OpenCV. |
| **Exp 05** | Write a Python function to analyze the histogram of an input image based on color levels. |
| **Exp 06** | Perform basic image processing and convert the image into an eroded image using the Erode function. |
